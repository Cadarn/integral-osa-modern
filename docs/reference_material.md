# Reference material for OSA analysis

Links to manuals and documentation that has been archived: https://www.cosmos.esa.int/web/integral/documentation

The legacy portal for links to data (hopefully): https://isla.esac.esa.int/isla/#/pages/home

The Offline Scientific Analysis (OSA) Guide: https://www.cosmos.esa.int/documents/332075/24154101/osa_inst_guide.pdf

Note the original webpage for data products and software was https://isdc.unige.ch/ and it is currently unavailable to any docs or code that references data here may need to find alternatives
